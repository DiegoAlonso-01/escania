Política de privacidad de EscanIA

Última actualización: 23 de octubre de 2026.

Quién la usa

EscanIA es un programa de uso personal. La única cuenta que lo autoriza es escaneaia@gmail.com, que pertenece a su propio dueño. No tiene otros usuarios.

Qué datos de Google usa

Con el permiso que da el dueño de la cuenta, EscanIA usa dos accesos de la API de Gmail:

  • Lectura de los mensajes de la casilla, para tomar los gastos, ingresos y avisos de pago que el propio usuario se envía.
  • Agregado de mensajes en la propia casilla, para dejar ahí los respaldos de la base y los resúmenes periódicos. El programa no envía correos a nadie, ni borra ni mueve los mensajes existentes.

Dónde quedan los datos

Lo que se lee se guarda solo en una base de datos en la computadora del usuario y en los respaldos que el programa deja en la misma casilla. No se envía a ningún servidor propio ni de terceros, no se comparte, no se vende y no se usa con fines publicitarios ni para entrenar modelos de inteligencia artificial.

El programa no guarda números de tarjetas ni datos de acceso a bancos.

Uso limitado

El uso de la información recibida de las API de Google cumple con la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo se revoca

El permiso se puede quitar en cualquier momento desde la cuenta de Google, en Seguridad > Conexiones con terceros, sin cambiar la contraseña. Para borrar los datos alcanza con eliminar la base local y sus respaldos.
